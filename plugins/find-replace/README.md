# 文件夹查找替换

在当前笔记或整个文件夹里批量替换文字。

## 两个入口

- 长按 md 文件 → 「在此笔记中替换…」
- 长按文件夹 → 「在此文件夹中替换…（223）」

菜单上直接显示有几个笔记。递归子文件夹，可随时取消勾选。

## 面板

```
查找    [ 沐安 ]
替换为  [ 苏晚 ]

☑ 区分大小写  ☐ 全字匹配  ☐ 正则表达式
☑ 含子文件夹  ☑ 跳过 YAML  ☑ 备份原文件
☐ 也改文件名

        [ 预览 ]  [ 全部替换 ]
```

## 先预览再替换

预览列出命中文件、各处上下文（命中词高亮），点文件名直接打开。
点「全部替换」还会再确认一次。

## 关键设计

- **跳过 YAML 默认开** —— 文件头 `title: 沐安传` 不会跟着变
- **备份默认开** —— 复制到 `替换备份/时间戳/原目录/`，备份目录自动排除在替换范围外
- **全字匹配对中文无效** —— 中文无词边界，只在查找串首尾是英文/数字时生效

## 命令

- 替换：当前笔记
- 替换：当前笔记所在文件夹
