# BookSmith 小说工作台

一本书 = 一个文件夹。

## 核心设计

插件**不存章节列表**，只存「书在哪、叫什么、封面是啥」。
章节结构每次都从文件夹实时读出来。

好处：你在任何地方增删章节（文件管理器、别的插件、Git），
这里**自动同步**，不会出现"插件里显示的跟实际文件对不上"。

## 侧边栏

装好重启后，BookSmith 会自动出现在**左侧栏**（跟 AI 写作助手一样），
不用先手动执行一次命令。

面板从上到下：

```
[新建] [切换] [管理]        ← 顶栏
┌──────────────────┐
│ [封面] 书名        │      ← 点封面/书名 = 编辑
│       作者         │
│ 3.2万 / 10.0万 32% │      ← 进度条
│ 今日 1200 字 · 8 章 │
└──────────────────┘
[写最新一章] [新建章节]      ← 四个快捷
[导出 TXT]   [编辑信息]
──────────────────
正文                        ← 散章（前言/大纲/后记）
  · 前言
  · 大纲
▾ 第一卷              3     ← 卷，点标题折叠
    · 第一章
    · 第二章
  · 后记
──────────────────
```

点章节直接打开。长按有菜单。

## 新建书籍

**只建一个空文件夹**，不预置 前言 / 大纲 / 后记。
章节你自己加，跟在 Obsidian 里建笔记一模一样。

**书名重复会自动加序号**（`测试书 2`），绝不覆盖已有文件夹——覆盖会丢稿子。

## 章节文件是干净的

新建的 md **不写任何 frontmatter**，所以 Obsidian 顶部不会有「笔记属性」区
（哪怕只有一行也要占两行高度）。文件名就是章节名。

排序记录存在插件数据里，也不写进文件 —— md 保持干净。

## 章节编号

新建章节时，文件名**已经填好序号**：

```
第001章          ← 书里还没有章节
第003章          ← 已有 001、002，自动 +1
```

你只要在后面接着写标题，比如「第003章 惊变」。

识别规则：找现有点大的「第N章」+1。兼容 `第1章`、`第001章`、`第 12 章` 三种写法。

## 拖动排序（能跨卷）

长按章节 **0.5 秒** → 振动一下，行变亮 → 拖到位置松手。

**可以跨分组拖：**

| 操作 | 效果 |
|---|---|
| 书根 → 拖进卷里 | 文件移到该卷文件夹 |
| 卷里 → 拖到书根 | 文件移回书根目录 |
| 拖到**卷标题**上 | 收进这卷，排在末尾 |
| 卷内上下拖 | 只改顺序 |

跨卷是真的移动 md 文件，不是显示层 trick。

如果振动后**再等 0.7 秒**还没拖动，就弹出菜单（重命名 / 删除等）。

> 技术说明：平时列表允许滚动（`touch-action: pan-y`），
> 长按那一瞬间切到 `none` 并用 `touchmove` + `preventDefault`
> 把手势从浏览器手里抢回来 —— 否则一拖就变成滚动列表。

排序记录存在插件数据里，**既不改文件名也不写 frontmatter**。

## 长按菜单

长按章节约 1.2 秒弹出（如果振动后 0.7 秒内开始拖动，就不会弹）。

- **章节** → 重命名 / 复制章节名 / 移到别的卷 / 删除
- **卷** → 重命名 / 在这卷里建新章节 / 删除这卷

## 封面

四条路：

- **从图库导入** —— 调安卓系统选择器，选完复制到 `BookSmith封面/`
- **从 vault 选图片** —— 网格预览，点一下就选
- **粘贴图片链接** —— 建议 https，http 在手机上常加载不出来
- **清除**

图库导入存的是 vault 路径，不是 base64——
一张图几百 KB 塞进 data.json 会把配置文件撑爆。

## 管理（每本书 6 个按钮）

| 按钮 | 做什么 |
|---|---|
| 切到这本 | 设为当前 |
| 编辑信息 | 书名/副标题/作者/目标字数/简介/封面 |
| 新建章节 | 选卷 + 填名，建完直接打开 |
| 导出 TXT | 预览章节数和字数，再决定导出还是复制 |
| 在文件夹打开 | 跳到面板，显示路径 |
| 删除 | **只删记录，不动文件** |

## 导出

复用 **Folder to TXT**，不重复实现合并逻辑。导出前会先告诉你：

```
章节数：8
总字数：约 3.2万 字
输出文件名：我的小说.txt
```

两个出口：导出到 vault / 复制到剪贴板。

没装 Folder to TXT 会明确提示，不会静默失败。

## 删除为什么只删记录

删文件是**不可逆**的，而且插件无法判断那些 md 是不是你还要的。

所以默认只删插件里的这本书的记录，vault 里的文件一个不动，
并且会把"有多少个文件、多少个文件夹"告诉你。
真要删干净，去文件管理器删，那是你自己可控的操作。

## 改书名

会连文件夹一起改名，内容不丢。

## 底部统计

```
今日字数        0 字
字数统计   0 / 1.0万
完成度          0%
写作天数        0 天
日均            0 字
              共 5 章
```

- **今日字数** —— 相对今天第一次打开时的增量
- **写作天数** —— 有产出的天数
- **日均** —— 总产出 ÷ 有产出的天数

## 命令（7 条）

打开面板 / 新建书籍 / 切换书籍 / 管理书籍 / 新建章节 / 导出当前书籍为 TXT / 刷新统计

## 依赖

需要 **Mogeo Core**。没启用时命令能注册但点了会提示（不会一开 Obsidian 就刷屏）。

导出需要 **Folder to TXT**（可选，没装就只是导出不能用）。
