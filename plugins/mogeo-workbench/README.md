# 创作工作台

把 vault 里**所有插件的功能**聚到一个面板里，自己摆。

## 核心：不用写死名单

工作台不认识任何具体插件。它每次打开都重新扫描：

- `app.commands` → 所有命令
- `app.plugins.manifests` → 所有插件信息

命令 id 形如 `插件id:命令id`，据此归到插件。
**前缀在 manifests 里找不到的，算 Obsidian 核心命令**（`app:` 开头那批）。

所以：**装个新插件，它和它的命令会自动出现**，不用改工作台一行代码。

## 三个 tab

### ★ 常用
你收藏过的命令和插件，按自己的分组摆放。

### 全部插件
按「已启用 → 有命令的 → 名字」排序。点插件名展开它的命令。

- 🟢 已启用　⚪ 未启用
- 每行右边 `⋯`：收藏整个插件 / 收藏它全部命令 / 改名字换图标 / 隐藏 / 去设置

### 新发现
装了但还没在工作台里看过的插件，带 `NEW` 角标。
点「全部标记为已读」清掉。

## 命令能怎么改

命令右边的按钮：

| 按钮 | 作用 |
|---|---|
| ☆ / ★ | 收藏 / 取消 |
| ⋯ | 更多 |

`⋯` 里：执行、收藏、**改名字**、**换图标**、**移到分组**、恢复原名、复制命令 ID。

长按命令或插件行 = 同一个菜单。

**自定义只是外挂修饰** —— 别名、图标、分组都存在工作台自己的数据里，
不去改任何插件本身的设置。卸掉工作台，别的插件毫发无损。

## 分组

长按命令 → 「移到分组」→ 可以选已有分组或新建。

设置页能改名、删除分组。

常见用法：建个「开写前」放 新建章节 / 朗读 / 查设定，
建个「收尾」放 导出 / 统计。

## 搜索

顶部搜索框同时搜**插件名**和**命令名**。
搜索时只重渲染列表，输入框不会失焦。

## 设置

- **显示 Obsidian 核心命令** —— 默认关，打开后能收藏核心命令
- **分组管理** —— 改名 / 删除 / 新建
- **清空全部收藏和自定义**

## 依赖

依赖 **Mogeo Core**。Core 没启用时：

- 命令照常注册（不会让插件加载失败）
- 打开面板会提示并跳设置页

## 命令（2 条）

- 打开创作工作台
- 重新扫描插件
