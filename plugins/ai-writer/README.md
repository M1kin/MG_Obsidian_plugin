# AI 写作助手

接入 OpenAI 兼容接口，三个用法。

## 先配接口

8 个服务商预设：DeepSeek、Kimi、硅基流动、通义千问、智谱、火山方舟、OpenAI、**自定义中转站**。

选「自定义」填地址（结尾一般 `/v1`）+ Key。

模型名不确定？点「**拉取**」自动列出。

### 装完第一件事：点「测试」

通了显示耗时，不通会直接说是 Key 错、余额不足还是模型名不对。**省掉 90% 排查时间。**

## 用法一：选中文字处理

11 个内置动作：续写 / 扩写 / 润色 / 精简 / 增强描写 / 优化对话 / 纠错 / 换说法 / 起标题 / 总结 / 提取设定

也可在弹窗底部写自由指令，如「把这段改得更压抑一点」。

结果可编辑，再决定「替换选中」或「插到后面」。生成中点「停止」保留已生成部分。

## 用法二：续写当前笔记

取光标前 3000 字（可调）当背景接着写。用 Kimi 可调到几万，AI 能记住前面情节。

## 用法三：侧边栏聊天

左侧栏。每条回复下有「复制」。记录自动保存。

## 命令（5 条）

AI 处理选中文字 / AI 续写当前笔记 / 打开 AI 聊天侧边栏 / 问 AI（弹窗）/ 测试 API 连接

## 依赖

Mogeo Core

## 隐私

API Key 明文存 `data.json`，别公开上传整个 vault。正文会发送到你配置的服务商。
