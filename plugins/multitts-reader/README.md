# MultiTTS Reader 朗读

右下角三按钮悬浮条：**播放 / 暂停 / 停止**。

## 三按钮区别

| 按钮 | 行为 |
|---|---|
| 播放 | 暂停中→继续；停止后→**从光标处重新开始** |
| 暂停 | 停在这句，再点播放继续 |
| 停止 | 彻底清空，再点播放重新开始 |

## 从光标处开始

光标点在想开始听的那行，再点播放。

- 光标在开头 → 读全文
- 光标在中间 → 从光标往后读
- 光标在末尾 → 提示没有内容

## 需要自备 TTS 服务

默认连 `127.0.0.1:8774`，**手机上要跑一个 TTS 服务**。

改地址：设置页「服务地址」，或编辑 `data.json` 的 `baseUrl`。

## 悬浮条自动出现

开机自动挂载，不用先执行命令。带退避重试。

## 命令（7 条）

朗读当前笔记（从光标处）/ 播放 / 暂停 / 停止 / 显示隐藏悬浮条 / 选择发音人 / 诊断
