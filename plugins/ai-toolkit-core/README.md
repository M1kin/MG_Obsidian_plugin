# Mogeo Core

套件中枢，其他插件都依赖它。**必须先装并启用。**

## 身份

1. **前置守卫** —— 子插件靠它判断能不能干活
2. **状态中心** —— 一个面板看全部插件启用状态
3. **打赏聚合** —— 第三方可接入，点插件名能打赏

## 设置页

- 插件状态（套件置顶 + 第三方在后）
- 一键检查 / 复制诊断信息
- 赞助作者（微信 / 支付宝 / 福利）
- 插件总览（冲突检查）

## 命令

- 插件状态：查看总览
- 插件状态：复制诊断信息
- 插件状态：检查插件冲突
