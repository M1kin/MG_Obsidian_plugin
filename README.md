# Mogeo 插件套件 · 使用指南

一套给 **Obsidian 手机端** 做的小说创作工具链，共 9 个插件。

从拆书、写作、改稿、朗读到导出，全流程覆盖。所有插件都能在安卓 / iOS 上跑，界面按手机竖屏设计。

## 三分钟上手

### 第一步：装 Core（必须）

**Mogeo Core 是整个套件的心脏**，其他插件都要它在场。

```
设置 → 第三方插件 → 关闭「安全模式」
     → 把插件文件夹放进  .obsidian/plugins/
     → 重启 Obsidian
     → 回到第三方插件列表，打开 Mogeo Core 的开关
```

> Core 没启用时，其他插件会提示你「需要启用 Mogeo Core」并自动跳到设置页。

### 第二步：装你需要的插件

| 我想…… | 装这个 |
|---|---|
| 把 md 合成一个 txt | Folder to TXT |
| 听 AI 念我的笔记 | MultiTTS Reader |
| 批量改人名 / 地名 | 文件夹查找替换 |
| 让 AI 帮我写 | AI 写作助手 |
| 把 AI 的回复念出来 | AI 回复朗读 |
| 管理一整本书 | 书籍写作 |
| 一个面板点完所有操作 | 创作工作台 |

**装完记得重启 Obsidian。**

### 第三步：验证

Core 设置页有个紫色「一键检查」按钮，点一下会显示每个插件是 🟢 可用 / 🟡 未启用 / ⚪ 未安装。

## 逐个详解

### 1. Mogeo Core —— 中枢

**它是干什么的**

三个身份合一：

1. **前置守卫** —— 其他插件靠它判断「能不能干活」
2. **状态中心** —— 一个面板看全部插件的启用状态
3. **打赏聚合** —— 第三方开发者可以接入，点插件名就能打赏

**界面**

```
✅ Core 已启用
　·　已启用 5 个　·　未启用 0 个

插件状态
搜索        [_______]
──────────────────
[AI 工具箱套件（4）]
🟢 文件夹查找替换     可用
🟢 AI 写作助手        可用
🟢 Folder to TXT      可用
🟢 MultiTTS Reader    可用
[其它插件]
🟢 Dataview           可用
──────────────────
一键检查    [检查]
诊断信息    [复制]

赞助作者
  [微信] [支付宝] [福利]

▸ 插件总览（7 个 · ⚠️ 2 处重叠）
```

**插件总览**（点开折叠）里有：

- **冲突检查** —— 找出功能重复的插件（比如同时装了两个 TTS）
- **已安装插件** —— 版本、开发者、插件 ID
- 带 💝 的插件行可以直接点开打赏

**3 条命令**

- 插件状态：查看总览
- 插件状态：复制诊断信息
- 插件状态：检查插件冲突

> 「复制诊断信息」在反馈问题时特别有用，会把平台和所有插件版本一起复制出来。

### 2. Folder to TXT —— 合并导出

**它是干什么的**

把一个文件夹里所有 md 按顺序合并成一个 txt，自动补章节标题。

适合：写完一本书要导出发到小说网站。

**怎么用**

长按文件夹 → 「合并文件夹为 TXT」

或者在命令面板搜「合并文件夹为 TXT」。

**输出效果**

```
第一章 惊变

（正文……）

第二章 入局

（正文……）
```

文件名取文件夹名，默认存在同一层。

**注意**

- 按文件名排序，所以建议用 `第001章` 这种带前导零的命名
- 会跳过 YAML frontmatter，不会把 `title: xxx` 导进去

---

### 3. MultiTTS Reader —— 朗读

**它是干什么的**

右下角一个悬浮条，三个按钮：**播放 / 暂停 / 停止**，不折叠。

```
[▶] [⏸] [■]   7/100
```

**三个按钮的区别**

| 按钮 | 行为 |
|---|---|
| **播放** | 暂停中 → 接着播；停止后 → **从光标处重新开始** |
| **暂停** | 停在这句，再点播放继续 |
| **停止** | 彻底清空，再点播放重新开始 |

**从光标处开始**

把光标点在想开始听的那一行，再点播放，就从那里读。

- 光标在开头 → 读全文
- 光标在中间 → 从光标往后读
- 光标在末尾 → 提示「光标之后没有内容了」

**需要自备 TTS 服务**

默认连 `127.0.0.1:8774`，也就是**你手机上要跑一个 TTS 服务**（或者其他能访问的地址）。

改地址：设置页「服务地址」。改端口也可以直接编辑 `data.json` 里的 `baseUrl`。

**7 条命令**

朗读当前笔记（从光标处）/ 播放 / 暂停 / 停止 / 显示隐藏悬浮条 / 选择发音人 / 诊断

> 悬浮条是**开机自动出现**的，不用先执行一次命令。

### 4. 文件夹查找替换 —— 批量改词

**它是干什么的**

在当前笔记、或整个文件夹的所有笔记里批量替换文字。

改主角名字、统一术语、批量修正错字，都靠它。

**两个入口**

- 长按 md 文件 → 「在此笔记中替换…」
- 长按文件夹 → 「在此文件夹中替换…（223）」← 菜单上直接显示有几个笔记

递归子文件夹，「含子文件夹」可随时取消，数量会跟着变。

**面板**

```
查找    [ 沐安 ]
替换为  [ 苏晚 ]

☑ 区分大小写  ☐ 全字匹配  ☐ 正则表达式
☑ 含子文件夹  ☑ 跳过 YAML  ☑ 备份原文件
☐ 也改文件名

        [ 预览 ]  [ 全部替换 ]
```

**先预览再替换**

预览会列出命中哪些文件、各自几处、每处上下文（命中词高亮），点文件名直接打开那篇。

点「全部替换」还会再确认一次：*「将替换 N 个文件中的 M 处」*。

**几个关键设计**

- **跳过 YAML 默认开** —— 改角色名时，文件头的 `title: 沐安传` 不会跟着变，只有正文改
- **备份默认开** —— 原件复制到 `替换备份/时间戳/原目录/`，保持目录结构。备份目录会自动排除在替换范围外
- **全字匹配对中文无效** —— 中文没有词边界，这个功能只在查找串首尾是英文/数字时才生效。中文按普通查找走

**2 条命令**

替换：当前笔记 / 替换：当前笔记所在文件夹

### 5. AI 写作助手 —— 让 AI 帮你写

**它是干什么的**

接入 OpenAI 兼容接口，三个用法：

1. **选中文字 → AI 处理**
2. **AI 续写当前笔记**
3. **侧边栏聊天**

**先配接口**

设置里有 8 个服务商预设，选完自动填地址：

DeepSeek、Kimi、硅基流动、通义千问、智谱、火山方舟、OpenAI、**自定义中转站**

选「自定义」填地址和 Key 就行（地址结尾一般是 `/v1`）。

> 模型名不确定？点「**拉取**」按钮，自动列出现有模型。

**装完第一件事：点「测试」**

设置页的测试按钮 —— 通了会显示耗时，不通会直接告诉你是 Key 错、余额不足还是模型名不对。**这步能省掉后面 90% 的排查时间。**

**用法一：选中文字处理**

选中一段文字，11 个内置动作任选：

续写 / 扩写 / 润色 / 精简 / 增强描写 / 优化对话 / 纠错 / 换说法 / 起标题 / 总结 / 提取设定

也可以直接在弹窗底部写「把这段改得更压抑一点」这种自由指令。

结果先在弹窗里，**可以编辑**，再决定「替换选中」还是「插到后面」。生成中点「停止」会保留已生成的部分。

**用法二：续写当前笔记**

取光标前 3000 字（可调）当背景接着写，插到光标处。用 Kimi 的话这个值可以调到几万，AI 能记住前面情节。

**用法三：侧边栏聊天**

左滑打开。每条回复下面有「复制」。记录自动保存，重启还在。

**5 条命令**

AI 处理选中文字 / AI 续写当前笔记 / 打开 AI 聊天侧边栏 / 问 AI（弹窗）/ 测试 API 连接

### 6. AI 回复朗读 —— 把 AI 的话念出来

**它是干什么的**

AI 写完，直接念给你听。不用盯着屏幕看。

**需要三个都在**

- Mogeo Core
- AI 写作助手
- MultiTTS Reader

设置页顶部会直接显示这三个的状态，缺哪个标 ✖。

**两种模式**

| 模式 | 效果 |
|---|---|
| 生成完朗读 | 回复结束后整段读 |
| **边生成边朗读** | AI 每写完一句就读，不用等全文 |

音色语速沿用 TTS 插件的设置。

**2 条命令**

停止朗读 / 重读最后一次 AI 回复

> 装了它之后，AI 写作助手的每条回复气泡上会多一个**朗读按钮**，点一下只读那一条。

---

### 7. TTS 诊断医生 —— 排障专用

**它是干什么的**

朗读失败时，帮你找出到底是哪一步出问题。

**测什么**

- **内容类型** —— 换行、表格竖线、数字英文、符号、emoji、长文本
- **长度梯度** —— 50 到 3000 字找临界点
- **并发** —— 1 / 3 / 5 个同时请求
- **真实分段** —— 拿你当前这篇逐段跑

**它最擅长抓这个**

```
❌ 44 字节空音频
   原因：服务端返回了空的 WAV 文件
```

—— 说明**发出去的文本没东西可念**。常见于表格分隔行 `| --- | --- |` 清洗后整段为空。

**3 条命令**

诊断：跑一遍合成测试 / 诊断：用当前笔记的真实分段测试 / 诊断：复制上次结果

> 平时用不上，可以禁用。需要时再打开。

### 8. 书籍写作 —— 一本书 = 一个文件夹

**它是干什么的**

小说工作台。**一本书就是一个文件夹**，章节就是里面的 md 文件。

**核心设计：不存章节列表**

插件只记「书在哪、叫什么、封面是啥」，章节结构**每次从文件夹实时读**。

所以你在任何地方增删章节（文件管理器、Git、别的插件），这里自动同步，不会出现「显示的跟实际对不上」。

**侧边栏（自动挂载）**

装好重启就出现在左侧栏：

```
[新建] [切换] [管理]
┌────────────────────┐
│ [封面] 我的小说      │
│       Mogeo        │
│ 3.2万 / 10.0万  32% │
│ 今日 1200 字 · 8章  │
└────────────────────┘
[写最新一章] [新建章节]
[导出 TXT]   [编辑信息]
▾ 第一卷          3
    · 第一章
```

**统计区**

```
今日字数        0 字
字数统计   0 / 1.0万
完成度          0%
写作天数        0 天
日均            0 字
              共 5 章
```

**章节自动编号**

新建章节时文件名已经填好：

- 书里还没有 → `第001章`
- 已有 001、002 → `第003章`

你接着写标题就行。`第1章` / `第001章` / `第 12 章` 三种写法都认。

**拖动排序（能跨卷）**

长按章节约 0.5 秒 → 振动一下，行变亮 → 拖到位置松手。

| 操作 | 效果 |
|---|---|
| 书根 → 拖进卷里 | 文件移到该卷文件夹 |
| 卷里 → 拖到书根 | 文件移回书根目录 |
| 拖到**卷标题**上 | 收进这卷，排末尾 |
| 卷内上下拖 | 只改顺序 |

跨卷是真的移动 md 文件。

> 如果振动后**再等 0.7 秒**还没拖动，就弹出菜单（重命名 / 删除等）。

**长按菜单**

- 章节 → 重命名 / 复制名 / 移到别的卷 / 删除
- 卷 → 重命名 / 建新章节 / 删除

**封面：三条路**

1. 从 vault 选图片（网格预览）
2. 从**安卓图库 / 文件**导入
3. 粘贴图片链接

存的是 vault 路径，不是 base64 —— 不然配置文件会被撑爆。

**导出整本书**

复用 Folder to TXT，导出前会先预览章节数和字数，再决定「导出到 vault」还是「复制到剪贴板」。

**8 条命令**

打开面板 / 新建书籍 / 切换书籍 / 管理书籍 / 新建章节 / 导出为 TXT / 刷新统计 / 重新扫描工具

**几个刻意的取舍**

- **删除只删记录，不动文件** —— 删文件不可逆，插件判断不了那些 md 你还要不要。删之前会告诉你「有 4 个文件、2 个文件夹」，真要删干净去文件管理器
- **新书只建空文件夹** —— 不预置前言/大纲/后记，章节你自己加，跟在 Obsidian 里建笔记一样
- **章节文件不写 frontmatter** —— 保持 md 干净，笔记顶部不会多出属性区

### 9. 创作工作台 —— 一个面板点完所有操作

**它是干什么的**

把 vault 里**所有插件的功能**聚到一个面板，自己摆。

**核心：不写死名单**

工作台不认识任何具体插件。每次打开都重新扫描所有命令和插件。

**所以：装个新插件，它和它的命令自动出现**，不用改工作台一行代码。

**三个 tab**

| Tab | 内容 |
|---|---|
| **★ 常用** | 你收藏的命令和插件，按自己的分组摆放 |
| **全部插件** | 按「已启用 → 命令多的 → 名字」排，点插件名展开命令 |
| **新发现** | 装了但还没看过的插件，带 NEW 角标 |

**能怎么改**

命令右边 `☆` 收藏，`⋯` 里：

执行 / 收藏 / **改名字** / **换图标** / **移到分组** / 恢复原名 / 复制命令 ID

长按命令行也是同一个菜单。

```
写作前
  📖 开新书         ← 原名「新建书籍」
  🔊 朗读当前笔记
```

> 自定义只是**外挂修饰** —— 别名、图标、分组都存在工作台自己的数据里，不改任何插件的设置。卸掉工作台，别的插件毫发无损。

**搜索**

顶部搜索框同时搜**插件名**和**命令名**。

**人性化细节**

- 未启用的插件点了会提示「XXX 还没启用，命令不会执行」，而不是静默无反应
- 搜索时只重渲染列表，输入框不会失焦

**2 条命令**

打开创作工作台 / 重新扫描插件

## 推荐工作流

### 写一本新书

```
1. 书籍写作 → 新建书籍（只建一个空文件夹）
2. 新建章节（自动编号 第001章）
3. 写 → AI 写作助手续写 / 润色
4. 边写边听：MultiTTS Reader
5. 中途改人名：文件夹查找替换
6. 写完：导出 TXT（复用 Folder to TXT）
```

### 日常码字

```
创作工作台 → 常用分组「开写前」
  📖 新建章节
  🔊 朗读当前笔记
  🔍 查找替换
```

### 边写边听

```
1. 打开笔记，光标点在想开始听的那行
2. MultiTTS Reader → 播放
3. 听到不对的地方 → 暂停 → 改 → 继续
4. AI 回复朗读开着的话，AI 写完自动念
```

## 依赖与开关

### 依赖链

```
Mogeo Core           ← 所有插件的地基
├── Folder to TXT
├── MultiTTS Reader
├── 文件夹查找替换
├── AI 写作助手
│   └── AI 回复朗读    ← 还要 MultiTTS Reader
├── TTS 诊断医生
├── 书籍写作
└── 创作工作台
```

**AI 回复朗读** 要求最严：Core + AI 写作助手 + MultiTTS Reader 三个都得在。

关掉 Core，其他插件会拒绝执行并跳到设置页 —— 这是**故意的**，不是 bug。

### 各插件的开关建议

| 场景 | 建议 |
|---|---|
| 只用朗读 | Core + MultiTTS Reader |
| 只用 AI | Core + AI 写作助手 |
| 只用工作台 | Core + 创作工作台 |
| 朗读出问题 | 临时打开 TTS 诊断医生 |
| 全都要 | 都开（九件套） |

## 常见问题

**Q：插件加载失败？**

检查是不是把整个文件夹套了一层。正确结构：

```
.obsidian/plugins/mogeo-core/main.js
                          manifest.json
```

不是 `.../mogeo-core/mogeo-core/main.js`。

**Q：点了命令没反应？**

大概率是 Core 没启用。插件会弹提示并自动跳到设置页，打开开关后**重启 Obsidian**。

**Q：悬浮朗读条不出现？**

- 确认 MultiTTS Reader 已启用
- 设置页里「显示悬浮条」是开的
- 重启一次（它会在布局就绪后自动挂，带重试）
- 命令面板搜「显示悬浮条」手动切一次

**Q：朗读报「合成失败：返回的音频为空」？**

先跑一遍 **TTS 诊断医生**。

如果是 **44 字节** → 服务端返回了空 WAV，说明发出去的文本没内容可念（常见于表格分隔行）。

**Q：AI 写作助手测试连不上？**

看错误提示：

- **401** → Key 错了或过期
- **429** → 频率限制，等一会
- **404** → 模型名不对，点「拉取」看实际有哪些
- **余额不足** → 去服务商充值
- **网络错误** → 检查地址结尾是不是 `/v1`

**Q：AI 读完再读笔记报错？**

已经修过了。如果还有，两个插件都更新到最新版。

**Q：书籍写作里章节不见了？**

之前有个渲染 bug（卷里章节不显示），1.2.0 已修。文件其实一直都在，只是显示不出来。更新插件即可。

**Q：拖拽排序拖不动？**

长按要**按满 0.5 秒**，会振动一下提示可以拖了。振动前拖 = 会被当成滚动列表。

**Q：怎么反馈问题？**

Core 设置页 → 「诊断信息」→「复制」，把内容一起发出来。里面包含平台和所有插件版本。
